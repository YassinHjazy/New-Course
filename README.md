# Addition of Integers

## 1. What Is Integer Addition?

**Addition** combines quantities or determines the total change between numbers.

For integers,

\[
a+b
\]

means adding the integer \(b\) to the integer \(a\).

Examples:

\[
3+4=7
\]

\[
-2+(-5)=-7.
\]

---

## 2. Addition on the Number Line

Integer addition can be understood using movement on the number line.

### Adding a positive number

Move to the **right**.

For example:

\[
3+4=7.
\]

Start at \(3\), then move four units right:

\[
3\rightarrow4\rightarrow5\rightarrow6\rightarrow7.
\]

### Adding a negative number

Move to the **left**.

For example:

\[
3+(-4)=-1.
\]

Start at \(3\), then move four units left:

\[
3\rightarrow2\rightarrow1\rightarrow0\rightarrow-1.
\]

This gives the basic idea:

\[
\boxed{\text{Add positive}\Rightarrow\text{move right}}
\]

\[
\boxed{\text{Add negative}\Rightarrow\text{move left}}
\]

---

## 3. Adding Two Positive Integers

When both integers are positive, add their magnitudes.

\[
5+3=8.
\]

\[
12+7=19.
\]

The result is positive.

---

## 4. Adding Two Negative Integers

When both integers are negative:

1. Add their absolute values.
2. Keep the negative sign.

For example:

\[
-4+(-7).
\]

First:

\[
4+7=11.
\]

Then keep the negative sign:

\[
\boxed{-4+(-7)=-11}.
\]

Another example:

\[
-8+(-3)=-11.
\]

---

## 5. Adding Integers With Different Signs

When the integers have different signs:

1. Find the difference between their absolute values.
2. Give the result the sign of the number with the greater absolute value.

Example:

\[
8+(-3).
\]

Compare:

\[
|8|=8,\qquad|-3|=3.
\]

Subtract:

\[
8-3=5.
\]

The larger absolute value belongs to \(8\), so the result is positive:

\[
\boxed{8+(-3)=5}.
\]

---

## 6. Another Example With Different Signs

Consider:

\[
-9+4.
\]

The absolute values are:

\[
|-9|=9,\qquad|4|=4.
\]

Subtract:

\[
9-4=5.
\]

The larger absolute value belongs to \(-9\), so the result is negative:

\[
\boxed{-9+4=-5}.
\]

---

## 7. When the Absolute Values Are Equal

If two integers have opposite signs but equal absolute values, their sum is zero.

For example:

\[
5+(-5)=0.
\]

And:

\[
-12+12=0.
\]

This happens because a number and its opposite cancel each other:

\[
\boxed{a+(-a)=0}.
\]

---

## 8. Addition Rules

The rules can be summarized as follows.

### Same signs

Add the absolute values and keep the common sign.

\[
(+)+(+)=+
\]

\[
(-)+(-)=-
\]

Examples:

\[
4+7=11
\]

\[
-4+(-7)=-11.
\]

### Different signs

Subtract the smaller absolute value from the larger absolute value and keep the sign of the number with the larger absolute value.

Examples:

\[
9+(-4)=5
\]

\[
-9+4=-5.
\]

---

## 9. Zero and Addition

Zero is the **additive identity**.

For every integer \(a\),

\[
\boxed{a+0=a}.
\]

Examples:

\[
7+0=7
\]

\[
-12+0=-12.
\]

Adding zero does not change a number.

---

## 10. Properties of Integer Addition

### Closure

If

\[
a,b\in\mathbb Z,
\]

then

\[
a+b\in\mathbb Z.
\]

Therefore, integers are **closed under addition**.

### Commutative Property

Changing the order does not change the sum:

\[
\boxed{a+b=b+a}.
\]

Example:

\[
3+(-7)=(-7)+3=-4.
\]

### Associative Property

Changing the grouping does not change the sum:

\[
\boxed{(a+b)+c=a+(b+c)}.
\]

Example:

\[
(2+3)+4=2+(3+4)=9.
\]

### Additive Identity

\[
\boxed{a+0=a}.
\]

### Additive Inverse

Every integer \(a\) has an additive inverse \(-a\):

\[
\boxed{a+(-a)=0}.
\]

## 12. Common Mistakes

### Mistake 1: Adding the signs incorrectly

For example:

\[
-5+(-3)
\]

is not \(2\).

The correct answer is:

\[
-5+(-3)=-8.
\]

### Mistake 2: Ignoring the larger absolute value

For:

\[
-12+5,
\]

the result is negative because

\[
|-12|>|5|.
\]

Therefore:

\[
-12+5=-7.
\]

### Mistake 3: Confusing addition with subtraction

\[
5+(-3)=2
\]

but

\[
5-(-3)=8.
\]

The two operations are related, but they are not identical.

---

## 13. Key Idea

The most useful conceptual interpretation is:

\[
\boxed{\text{Integer addition describes movement on the number line.}}
\]

- Add a positive → move right.
- Add a negative → move left.

This interpretation will become useful later when studying subtraction, algebra, vectors, and functions.
